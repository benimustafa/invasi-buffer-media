# KUNCI: Promo Canva Collection (Beni, 25 Nov 2026)

Format baku carousel promo koleksi template Canva di @invasistudio (+ X dengan media sama).

- Isi: 4-5 template dari SATU payung/koleksi (bukan semua template bertema sama).
- Layout: Figma "Invasi Studio Stock Collection" > halaman "Template Canva Collection" (fileKey 1VFh5YusoUVztChYTDuLIR).
  Isi slot boleh disesuaikan dengan jumlah template; gaya tetap (kertas #efebdf, tinta #2b2a14,
  Instrument Serif untuk headline, IBM Plex Mono untuk teks kecil, radius 6 cover / 20 pano).
- Slide 1 cover = MOTION Remotion (`remotion/`, composition `c-cover`, 5 dtk, 1080x1350).
  3 kartu, tiap kartu memutar 2 template dengan tempo sama; di setiap saat 3 kartu menampilkan
  3 template berbeda (tidak boleh kembar). Versi diam `c-cover-still` untuk X.
- Slide 2-4: panorama menyambung, 1 template per slot, label mono "01 / NAMA · pemakaian".
  Template berlatar mirip kertas diberi garis tepi tipis #d8d3c4.
- Slide 5: CTA "GET THE FULL SET ON CANVA." + grid template utuh (tanpa crop).
- Script panorama/CTA: `build_pano_4templates.py`.
